Privacy Policy

TypeFlow stores progress data only in this browser using local storage. This includes XP, rank, prestige, test count, settings, weak words, and daily challenge records.

This version does not send scores to a server and does not share score data online. A production online version would need server authentication, rate limiting, abuse detection, and server-side score validation.

The page loads fonts from Google Fonts. Clearing this browser's site data for TypeFlow will remove local progress, results, ranks, and settings.
